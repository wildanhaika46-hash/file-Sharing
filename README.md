📁 Multi-User File Sharing
A website for multi-user file sharing with a modern and intuitive interface.

🌟 Features
🔐 User Authentication - Registration and login system
📤 File Upload - Supports multiple file uploads
📥 File Download - Easy file downloading
🔗 File Sharing - Generate shareable links for each file
🗑️ Delete Files - File management for uploaded items
📱 Responsive - Optimal display on desktop and mobile
💾 Local Storage - Data stored in the browser (localStorage)
🚀 How to Use
Save the code as an HTML file (e.g., file-sharing.html)
Open the file in a web browser (Chrome, Firefox, Edge, etc.)
Register a new account or log in with an existing one
Upload files using the choose file button
Manage files through the user dashboard
👥 For New Users
Click the "Register" tab
Fill in username, email, and password (min. 6 characters)
Click the "Register" button
Log in with the registered username and password
📊 File Management
Upload: Select files and click "Upload File"
Download: Click the "Download" button on the file card
Share: Click the "Share" button to view the share link
Delete: Click the "Delete" button to remove the file
⚠️ Important Notes
This website runs entirely in the browser
Files are not uploaded to any server
Data is stored in the browser's localStorage
Data will be lost if browser cache is cleared
For production use, a backend server is required
🛠️ Technologies Used
HTML5
CSS3 (with gradients and animations)
JavaScript (ES6+)
LocalStorage for data storage
Responsive design with CSS Grid and Flexbox
📞 Support
If you encounter issues:

Ensure JavaScript is enabled in your browser
Check the browser console for error messages (F12)
Clear cache and try again
🔒 Security
This is a demo version for educational purposes
Passwords are stored as plaintext (not secure for production)
Each user can only access their own files
